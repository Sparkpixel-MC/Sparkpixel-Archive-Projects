## ✨ 简介

本仓库是我们团队多年来开发的各类内部项目的**存档**。这些项目已不再积极维护，但保留在此作为我们成长、实验和历史工作的记录。欢迎随意查阅、学习，或在相应许可证允许的范围内复用其中开源的组件。

---

## 🗂️ 项目总览

| 项目 | 简介 | 技术栈 |
|---------|-------------|------------|
| **Donate-JS-Background** | 捐赠页面的交互式 JavaScript 背景特效（如粒子、动态渐变）。 | `JavaScript` `HTML5 Canvas` |
| **Insurance** | Minecraft 服务器插件，用于物品保险与保护。 | `Java 17` `Maven` `Spigot/Paper` |
| **QQ-Bot** | 服务于 Minecraft 服务器的 QQ 机器人：消息处理、服务器监控、玩家查询、支付与图片生成。 | `Python` `FastAPI` |
| **QQ-Group-Bot** | 带 AI 知识库的 QQ 群机器人：本地向量知识库、MCP 知识库服务与服务器监控。 | `Python` `FastAPI` |
| **Spark-Web-Old** | Spark 官网或网页面板的旧版本。 | `PHP` `HTML/CSS` `JS` |

## 📁 项目详情

<details>
<summary><strong>🔹 Donate-JS-Background</strong></summary>

- **最初用途**：为捐赠页面提供吸睛的动态背景，提升互动效果。
- **主要特性**：轻量、颜色/粒子可配置、无外部依赖。
- **目录**：`/Donate-JS-Background/`

</details>

<details>
<summary><strong>🔹 Insurance</strong></summary>

- **最初用途**：Minecraft 服务器插件，让玩家为自己的物品投保以防丢失。
- **主要特性**：物品保护、通过 Vault 对接经济系统、使用 Maven 构建，面向 Spigot/Paper 服务端（Java 17）。
- **目录**：`/Insurance/`

</details>

<details>
<summary><strong>🔹 QQ-Bot</strong></summary>

- **最初用途**：服务于 Minecraft 服务器社区的 QQ 机器人。
- **主要特性**：私聊/群聊消息处理、带在线人数历史记录的服务器状态监控、玩家 UUID/名称查询、支付处理与动态图片生成。
- **目录**：`/QQ-Bot/`

</details>

<details>
<summary><strong>🔹 QQ-Group-Bot</strong></summary>

- **最初用途**：面向社区的、带 AI 问答功能的 QQ 群机器人。
- **主要特性**：本地向量知识库与文档向量化、MCP 知识库客户端/服务端、AI 客户端接入、群消息处理与服务器监控。
- **目录**：`/QQ-Group-Bot/`

</details>

<details>
<summary><strong>🔹 Spark-Web-Old</strong></summary>

- **最初用途**：Spark 项目第一代官网 / 网页门户。
- **包含内容**：旧版 PHP 后端、HTML 模板与早期前端实验代码。
- **目录**：`/Spark-Web-Old/`

</details>
