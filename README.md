## ✨ Introduction

This repository is an **archive** of various internal projects developed by our team over the years. They are no longer actively maintained, but remain here as a record of our progress, experiments, and legacy work. Feel free to explore, learn from them, or reuse any open-sourced components under the respective licenses.

---

## 🗂️ Projects Overview

| Project | Description | Tech Stack |
|---------|-------------|------------|
| **Donate-JS-Background** | Interactive JavaScript background effect for donation pages (e.g., particles, dynamic gradients). | `JavaScript` `HTML5 Canvas` |
| **Insurance** | Minecraft server plugin for item insurance and protection. | `Java 17` `Maven` `Spigot/Paper` |
| **QQ-Bot** | QQ bot for the Minecraft server: message handling, server monitoring, player lookups, payments, and image generation. | `Python` `FastAPI` |
| **QQ-Group-Bot** | QQ group bot with an AI knowledge base: local vector knowledge base, MCP knowledge-base service, and server monitoring. | `Python` `FastAPI` |
| **Spark-Web-Old** | The old version of Spark's official website or web dashboard. | `PHP` `HTML/CSS` `JS` |

## 📁 Project Details

<details>
<summary><strong>🔹 Donate-JS-Background</strong></summary>

- **Original purpose**: Provide an eye-catching animated background for donation pages to encourage engagement.
- **Key features**: Lightweight, configurable colors/particles, no external dependencies.
- **Folder**: `/Donate-JS-Background/`

</details>

<details>
<summary><strong>🔹 Insurance</strong></summary>

- **Original purpose**: Minecraft server plugin that lets players insure their items against loss.
- **Key features**: Item protection, economy integration via Vault, built with Maven for Spigot/Paper servers (Java 17).
- **Folder**: `/Insurance/`

</details>

<details>
<summary><strong>🔹 QQ-Bot</strong></summary>

- **Original purpose**: QQ bot serving the Minecraft server community.
- **Key features**: Private/group message handling, server status monitoring with player-count history, player UUID/name lookups, payment handling, and dynamic image generation.
- **Folder**: `/QQ-Bot/`

</details>

<details>
<summary><strong>🔹 QQ-Group-Bot</strong></summary>

- **Original purpose**: QQ group bot with AI-powered Q&A for the community.
- **Key features**: Local vector knowledge base with document vectorization, MCP knowledge-base client/server, AI client integration, group message handling, and server monitoring.
- **Folder**: `/QQ-Group-Bot/`

</details>

<details>
<summary><strong>🔹 Spark-Web-Old</strong></summary>

- **Original purpose**: First-generation official website / web portal of the Spark project.
- **What's inside**: Old PHP backend, HTML templates, and early frontend experiments.
- **Folder**: `/Spark-Web-Old/`

</details>

## ⚠️ Important Notes

- 🔐 **Credentials** – Any API keys or secrets originally present have been revoked or removed. Do not reuse old credentials.
- 📚 **Learning reference** – Feel free to study the code structure, but we recommend not using these projects in production.
